# 👴 SilverCompanion / elder-list

> **老人名录** — 记录需要陪伴的老人信息及苦难深度评估

---

## 📋 这是什么？

本仓库是 SilverCompanion 项目的 **老人信息库**。所有登记需要陪伴的老人都会在这里建档，便于陪伴者匹配和任务追踪。

---

## 📊 苦难深度指数（L0-L4）

根据 H/E/F 三维标签综合评估，确定每位老人的苦难深度等级：

| 等级 | 说明 | 对应报酬 |
|:---:|------|:---:|
| **L0** | 仅需社交陪伴 | 80 元/次 |
| **L1** | 轻度生活协助 | 120 元/次 |
| **L2** | 中度照护需求 | 150 元/次 |
| **L3** | 重度照护 + 临终陪伴 | 200 元/次 |
| **L4** | 紧急干预 | 200 元/次 + 应急物资 |

---

## 📝 档案结构

每位老人的档案包含：

```
老人称呼: 张爷爷
所在城市: 成都
年龄: 78
健康状况: H-（需要照护）
经济状况: E-（困难）
家庭结构: F-（完全无依靠）
苦难深度: L3
登记日期: 2026-08-20
当前陪伴者: 待匹配
陪伴任务记录: [链接]
```

---

## 🏛️ 核心原则

- **11条尊严铁律（D1-D11）** 是不可触碰的底线
- 所有老人信息严格保密，仅用于项目匹配
- 家属/代理人可代为登记
